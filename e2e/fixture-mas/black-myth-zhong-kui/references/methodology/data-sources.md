# 数据来源指南（Data Sources Guide）

本文件定义《黑神话·钟馗》研究的数据来源类型、可信度评级、谨慎使用项与 SRC 记录格式。所有收集代理必须遵守；核验代理据此评级。

## 数据来源类型与可信度

### 1. 官方第一手来源（Priority: 高 / Credibility: 高）

- 游戏科学官网与官方公告、官方 B 站/微博/X 账号发布的预告与声明
- Steam / PlayStation 商店页（游戏页、新闻、公告、愿望单公开信息）
- 官方媒体渠道的开发者访谈原文（如官方合作发布的采访文字稿）
- 官方发布的销量声明（如"销量突破 X 万份"公告）

### 2. 权威游戏媒体（Priority: 高 / Credibility: 中-高）

- IGN（含 IGN 中国）、Gamespot、VGC、Eurogamer 等国际主流游戏媒体
- 游民星空、机核网、触乐、游戏研究社（游研社）、3DM 等中文权威媒体
- 此类来源适合：事件报道交叉验证、媒体对预告/演示的**描述性**报道
- 媒体**观点/预测**内容（评测预判、销量预测文）仅作为"媒体观点"引用，不得当作事实

### 3. 行业分析机构与数据平台（Priority: 中 / Credibility: 中-高，须注明口径）

- Niko Partners、Newzoo 等机构公开报告（如可见）
- 券商/咨询公司研报（如公开）
- SteamDB、VG Insights、Gamalytic 等销量/愿望单**估算**平台：**所有数字均为估算模型输出，引用时必须显式标注"估算值"及其平台与抓取时间**

### 4. 社区与 UGC（Priority: 低 / Credibility: 低，仅作线索）

- 贴吧、NGA、Reddit、B 站评论区、个人博客、自媒体视频
- **不得单独作为事实来源**；仅用于发现线索、补充检索词，或与权威来源交叉时作为旁证（旁证仍需低可信度标注）

## 谨慎使用或避免的来源

- 无来源凭据的自媒体"爆料"、营销软文
- 二手转述（"据称""网传"且无法找到一手来源的内容）
- 明显的商业推广内容
- 预测性内容被当作事实引用（预测必须注明"预测/推断"性质）

## 抓取要求（BHV-05，收集阶段必须遵守）

1. **搜索结果是线索，不是数据**：摘要不得引用，必须抓取原网页全文。
2. **抓不到即弃用**：页面无法抓取时，换替代 URL 或同主题其他来源；找不到可访问来源则记录信息缺口，**绝不使用搜索摘要顶替**。
3. **保存逐字原文**：抓取工具返回的内容原样保存，禁止要点提炼、转述、重组为列表、增删小标题。
4. **自检**：保存文件长度应接近抓取内容；若明显缩水（如 1/10）判定为摘要，须重做。
5. **关键数据交叉**：销量数字、发售日期、平台、定价等关键事实尽量收集 ≥2 个独立来源。

## SRC 记录格式（收集阶段统一）

```markdown
## [SRC-{前缀}{序号}] 文章/页面标题

**Source URL**: https://example.com/article       ← 单一裸 URL，不得附注
**Fetch Time**: 2026-08-29T12:00:00Z
**Source Type**: 官方公告 / 权威媒体 / 商店页面 / 行业报告 / 数据平台 / 其他
**Credibility**: 高 / 中 / 低                    ← 依据来源权威性，与内容好坏无关
**Original Content**:

[抓取到的完整原文，逐字保留]
```

规则：

- 一个 SRC 块 = 一个来源（一个 URL、一次抓取、一段原文）；多来源支撑同一观点时写多个 SRC 块
- Source URL 字段**禁止**加入括号注释、双 URL、抓取说明——来源质量说明放入可信度/来源类型字段
- 编号前缀：初始扫描 `SRC-OVW-`；深度研究按主题 `SRC-T{主题代码}-`（如 `SRC-T05-`），序号连续
- 页面未能抓取成功时**不写 SRC 块**（该信息不可用）

## 引用规则（分析/报告阶段）

- 唯一合法引用来源：核验后清单 `workspace/04.data_verification/verified_sources.md`
- "保留"来源：正常引用；"降级"来源：引用时显式注明（如"估算值""低可信度"）；"剔除"来源：禁止引用
- 引用格式：正文行内 `[SRC-xxx]`，报告末尾参考来源节展开为完整条目

## 质量检查清单

- [ ] 每条原始材料都有可访问的 URL 与抓取时间
- [ ] 抓取内容为逐字原文（无摘要化痕迹）
- [ ] 关键数据来源 ≥2 个独立来源或明确标注单一来源
- [ ] 所有引用都在核验后保留清单内
- [ ] 估算类数据（SteamDB 等）均标注"估算"
