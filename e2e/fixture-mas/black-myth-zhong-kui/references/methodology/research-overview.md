# 研究总览（Research Overview）

## 研究主题

《黑神话·钟馗》的产品特点，以及基于公开信息对其预期销量的预估。

## 核心研究问题

1. **《黑神话·钟馗》有什么特点？** 具体分解为：
   - 题材与叙事：钟馗传说的改编方式、世界观设定、叙事结构、文化表达
   - 美术与视听：美术风格、场景与角色设计、音乐音效
   - 玩法与系统：动作设计、关卡结构、成长系统、特色机制
   - 技术与平台：开发引擎、目标平台、技术特征
   - 市场运营：定位、定价、宣发、预售与版本构成（如有公开信息）
2. **预期销量多少？** 具体分解为：
   - 基准锚定：《黑神话：悟空》经核验的销量轨迹与市场容量
   - 调整因子：品牌续作效应、平台覆盖、发售窗口、定价、宣发规模、愿望单/预售数据（如有）、市场环境
   - 情景预估：乐观 / 基准 / 保守三档区间，附关键假设与敏感性

## 研究范围

**包括**：

- 官方公开信息（官网、官方账号、商店页、官方公告、开发者访谈）
- 权威游戏媒体报道与分析
- 行业/数据平台公开数据（须注明估算性质）
- 社区讨论中**可被独立验证**的事实线索（仅作交叉线索）

**排除**：

- 无法核验的传闻与"舅舅党"爆料（未获官方或权威来源证实前不得作为事实）
- 个人主观评价作为事实使用
- 非公开内部信息

## 研究立场（价值取向与原则）

- **客观中立**：正面成就与风险问题并陈，不因系列前作成功而预设乐观结论，也不刻意唱衰。
- **事实与推断分离**：所有事实带可核验引用；推断明确标注"推断"及其依据；销量为"预估区间"而非"确定数字"。
- **不确定即披露**：信息缺口、矛盾信息、单一来源、估算数据都要在报告中显式披露。
- **可追溯**：报告中每个可核验事实都能沿 [SRC-xxx] 回溯到核验后保留的原始来源（QUA-03）。

## 方法总览（多阶段流水线）

1. 初始扫描：形成《黑神话·钟馗》公开信息总览（01.initial_scanner）
2. 问题设计：基于概览逆向工程 + 立场盲点识别，产出主题化研究问题清单（02.question_designer，STR-07）
3. 深度资料收集：按主题并行抓取逐字原文（03.deep_researcher，BHV-05）
4. 数据核验：独立上下文 100% 核验全部 SRC（04.data_verifier，QUA-03）
5. 特点分析与销量预估：主题分析 + 综合分析（05.analyzer）
6. 论证核验：独立上下文核验分析引用与论证（06.argument_verifier，QUA-03）
7. 报告分节撰写与装配：分节独立撰写 + 脚本装配（07.section_writer，STR-05）
