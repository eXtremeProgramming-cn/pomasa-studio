# 分析方法指南（Analysis Methods Guide）

本文件定义《黑神话·钟馗》研究的两大分析框架与产出格式。分析代理（05.analyzer）必须严格遵循；论证核验代理（06.argument_verifier）据此核验。

## 分析框架 A：游戏特点分析（五维框架）

对游戏特点按以下五个维度组织分析，每个维度回答三个问题：**实锤了什么（官方/商店页证据）、报道了什么（媒体描述）、推断了什么（基于证据的合理解读）**。

### A1 题材与叙事

- 钟馗传说的改编方式（人物、故事内核、与民俗传说的关系）
- 世界观设定（幽冥世界/神鬼体系的呈现）
- 叙事结构线索（预告叙事、章节、角色群像）
- 文化表达（美术中的民俗元素、中式审美表达）

### A2 美术与视听

- 美术风格（写实/写意、场景氛围、色调）
- 角色与怪物设计（钟馗形象、神鬼谱系）
- 音乐与音效（公开物料中可感知的风格线索）

### A3 玩法与系统

- 动作设计与战斗系统（公开演示/试玩报道中的线索）
- 关卡与探索结构
- 成长系统与角色养成
- 特色机制（区别于前作或同类作品的设计）

### A4 技术与平台

- 开发引擎与技术特征（公开信息为准，勿臆测）
- 目标平台（PC/主机/其他）与性能相关公开信息
- 本地化/语言版本

### A5 市场运营

- 产品定位与定价（公开价格/版本信息）
- 宣发节奏（预告、演示、展会、试玩安排）
- 预售/愿望单（如有公开数据）
- 与系列前作的联动运营（捆绑、DLC、周边）

## 分析框架 B：预期销量预估（三层法）

**总体原则：销量预估是"基于核验事实 + 明确假设"的区间判断，不是单点断言。所有数字保留原始口径（时间点、币种、单位、来源性质）。**

### B1 基准锚定

- 收集《黑神话：悟空》经核验的销量轨迹（各关键时间点的累计销量，区分：官方声明 / 权威媒体报告 / 第三方估算）
- 记录口径差异（如"出货量 vs 销量"、估算平台不同）
- 得出"系列前作的可比市场容量曲线"，作为本作预估的锚

### B2 调整因子分析

对每个因子给出**依据（引用）或显式标注"假设"**：

| 因子 | 方向 | 评估要点 |
|------|------|----------|
| 品牌续作效应 | + / - | 悟空口碑沉淀的用户基数；续作高预期带来的压力 |
| 平台覆盖 | + / - | 首发平台数量与装机规模 |
| 发售窗口 | + / - | 档期竞争（同期大作）、节假日效应 |
| 定价与版本 | + / - | 价格带、豪华版构成对客单价影响 |
| 宣发规模 | + / - | 预告热度、展会传播、预售开启情况 |
| 愿望单/预售数据 | + / - | Steam 愿望单排名（估算平台数据须标注） |
| 市场环境 | + / - | 国产单机热度、PC/主机玩家规模趋势 |
| 预期落差风险 | - | 续作口碑风险对长尾销量的影响 |

### B3 情景预估

给出三档**区间**：

- **乐观**：核心假设全部兑现（如全平台首发、档期有利、口碑延续）
- **基准**：多数假设中性兑现
- **保守**：延期、口碑争议、档期恶劣等情景

每档必须附带：区间范围（可引用估算平台区间或给出推算逻辑）、核心假设清单、与基准锚定的对应关系（如"约为前作同期销量的 X%"并说明逻辑）。

### B4 假设与敏感性

- 列出全部关键假设：假设 → 若失效的销量影响方向
- 明确说明：本预估**不构成投资建议**；仅基于报告撰写时点的公开信息

## 分析过程（theme 与 synthesis 实例通用）

1. 只引用 `verified_sources.md` 保留清单内的 SRC；降级来源显式注明；剔除来源绝不引用
2. 逐问分析：先给结论，再给证据（带引用），再给不确定性
3. 事实与推断分离：事实用"据 [SRC-xxx]"；推断用"推断：…（依据：…）"
4. 信息缺口如实列出：不脑补、不猜测填充
5. 矛盾信息并列呈现，不作自行取舍；交由整体结论披露

## 分析结果存储格式

### 主题分析（theme）

```markdown
# {TOPIC_NAME} 分析（{TOPIC_CODE}）

## 分析结论（先行）
- 结论 1（[SRC-xxx]）
- …

## 逐问分析
### 问题 1：…
- **事实**：…（[SRC-xxx]；估算/低可信度须注明）
- **推断**：…（依据：…）
- **不确定性**：…

## 本主题信息缺口
- …
```

### 综合分析（synthesis）

```markdown
# 综合分析

## 一、《黑神话·钟馗》特点总结
## 二、预期销量预估（基准锚定 / 调整因子 / 三档情景区间表 / 假设与敏感性）
## 三、主要不确定性与风险
## 四、结论（3–5 条，可进入报告正文）
```

## 分析质量要求（QUA-01）

- **证据充分**：每项论断有具体来源或显式假设；禁止无依据的"可能/大概"论断
- **逻辑严谨**：因果链清晰；禁止"前作成功 ⇒ 本作必然成功"式跳跃；结论强度不超出证据强度
- **客观公正**：正面与风险并陈；估算与事实绝不混淆表达
- **可追溯**：所有引用映射到核验保留清单；关键数字注明时间点与口径

## 质量检查清单

- [ ] 五个特点维度均已覆盖（无证据的维度标注"暂无公开信息"而非跳过）
- [ ] 销量预估为三档区间 + 假设清单，无单点断言
- [ ] 所有引用均来自核验后保留来源
- [ ] 事实与推断显式区分
- [ ] 信息缺口、矛盾、估算数据均已披露
