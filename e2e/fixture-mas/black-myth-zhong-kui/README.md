# 《黑神话·钟馗》特点与预期销量研究 MAS

一个声明式多智能体研究系统：基于公开网络信息，研究《黑神话·钟馗》的产品特点，并对其预期销量给出情景区间预估（乐观/基准/保守），最终产出中文 Markdown 研究报告。

## Built with POMASA

This system was generated by **POMASA** (Pattern-Oriented Multi-Agent System Architecture) — a pattern language + generator for declarative multi-agent systems.

- **POMASA repository**: https://github.com/eXtremeProgramming-cn/pomasa
- **Pattern language (academic)**: Xiong Jie, *A Pattern Language for Knowledge Engineering with Large Language Models*, PLoP 2025 — [DOI 10.64346/PLoP2025p02](https://doi.org/10.64346/PLoP2025p02)

The agent blueprints reference architectural patterns by ID (`COR-01`, `STR-06`, `BHV-02`, `QUA-03`, etc.) — these are POMASA patterns. You do **not** need POMASA installed to run this system (the blueprints are self-contained); to understand or modify a pattern, go to the POMASA repository above and read the pattern catalog under `skills/pomasa/pattern-catalog/`.

## 流水线（8 阶段）

```
01.initial_scan ──> 02.question_list ──> 03.deep_research(并行) ──> 04.data_verification
      ──> 05.analysis(并行+综合) ──> 06.argument_verification ──> 07.sections(并行) ──> 08.report
```

数据沿文件系统流动（STR-02 文件系统数据总线）：每阶段产物落盘为独立目录，界间通过目录约定传递，全部中间产物可审查。

## 如何运行

本系统需在具备 AI 理解的智能运行时（如 DSH、Claude Code、Cursor 等）中执行，运行时需提供文件读写、子代理（subagent）与网页搜索/抓取能力。

1. 进入项目目录：`cd black-myth-zhong-kui`
2. 启动编排者（一次调用即驱动全流水线）：

   > 请读取 `agents/00.orchestrator.md` 并严格按照该 Blueprint 执行。

3. 等待各阶段完成（深度研究/分析/分节阶段会以 ≤7 的批次并行执行）。
4. 交付物：`workspace/08.report/final_report.md`（也可在 `workspace/` 中逐层查看中间产物）。

运行约束说明：

- 编排者会在 `workspace/run.json` 中记录各阶段状态（OBV-03），中断后可从文件恢复判断进度。
- 若某阶段代理上报"无法完成"，编排者将记录到 `wip/notes.md` 并上报；完成标准不可降低（BHV-02）。

## 如何调整

- **改研究范围/立场**：编辑 `references/methodology/research-overview.md`
- **改数据来源与可信度**：编辑 `references/methodology/data-sources.md`
- **改分析框架或销量预估方法**：编辑 `references/methodology/analysis-methods.md`
- **改报告结构/格式**：编辑 `references/methodology/output-template.md`（如需改分节方案须同步 `agents/07.section_writer.md` 与装配脚本）
- **改领域背景线索**：编辑 `references/domain/black_myth_series_background.md`
- **改代理行为/完成标准**：编辑对应 `agents/NN.xxx.md`
- **改运行划分**：编辑 `pomasa.json` 的 `work` 段（当前为 single）
- **重要**：改动 Blueprint 中的 Artifact 声明后，应同步更新 `pomasa.json` 的 `stages[].contracts[]`（OBV-01 要求生成器保持二者一致）
