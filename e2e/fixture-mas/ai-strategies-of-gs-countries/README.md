# 全球南方 AI 战略国别研究 MAS

一个声明式多智能体研究系统：按国别分别研究全球南方各国有什么样的 AI 战略，深入调研四个方向——AI 基建、应用、治理与能力建设的问题与前景；地缘政治背景下与中国和美国分别的关系；立法、产业政策与国际合作策略；影响该国 AI 战略的关键政府部门、政治家与思想领袖。每个国家产出独立的中文 Markdown 研究报告。

## Built with POMASA

This system was generated by **POMASA** (Pattern-Oriented Multi-Agent System Architecture) — a pattern language + generator for declarative multi-agent systems.

- **POMASA repository**: https://github.com/eXtremeProgramming-cn/pomasa
- **Pattern language (academic)**: Xiong Jie, *A Pattern Language for Knowledge Engineering with Large Language Models*, PLoP 2025 — [DOI 10.64346/PLoP2025p02](https://doi.org/10.64346/PLoP2025p02)

The agent blueprints reference architectural patterns by ID (`COR-01`, `STR-06`, `BHV-02`, `QUA-03`, etc.) — these are POMASA patterns. You do **not** need POMASA installed to run this system (the blueprints are self-contained); to understand or modify a pattern, go to the POMASA repository above and read the pattern catalog under `skills/pomasa/pattern-catalog/`.

## 流水线（每国 7 阶段）

```
01.country_scan ──> 02.deep_research(按方向×4并行) ──> 03.verification(100%覆盖)
      ──> 04.analysis(按方向×4并行) ──> 05.argument_verification ──> 06.sections(按分节×7并行)
      ──> 07.report(装配 + 文末脚注定义区)
```

数据沿文件系统流动（STR-02 文件系统数据总线）：每阶段产物落盘为独立目录，界间通过目录约定传递；全部中间产物可审查；每阶段维护 `index.json`（OBV-01）供 UI 渲染。

数据血缘（QUA-03）：原始材料编号 `SRC-{dir}-{NN}` → 分析材料 `ANA-{dir}-01`（引用 SRC）→ 报告脚注 `[^SRC-xxx]`（文末定义区）→ 外部可核验 URL。两次独立上下文核验：收集后数据核验（03）+ 分析后论证核验（05）。

| STR-06 | Methodological Guidance | Required | 五份方法论文件约束数据、分析、输出 |

| STR-03 | Workspace Isolation | Recommended | 所有 Blueprint 开头声明项目内隔离 |
| STR-04 | Business-Driven Agent Design | Recommended | 按业务步骤划分 7 个阶段代理并编号 |
| STR-05 | Composable Document Assembly | Recommended | 分节并行撰写 + 脚本机械装配 |
| STR-08 | Pandoc-Ready Markdown | Recommended | 用户隐含规格：脚注/Pandoc 兼容格式 |
| BHV-01 | Orchestrated Agent Pipeline | Recommended | 编排者调度 7 阶段流水线 |
| BHV-02 | Faithful Agent Instantiation | Required | 每次调用让子代理自读 Blueprint + 逐项验收 |
| BHV-03 | Parallel Instance Execution | Optional | 深度收集/分析/分节按方向或分节并行（批 ≤7） |
| BHV-05 | Grounded Web Research | Recommended | 搜索只做线索，全部抓取逐字原文 |
| BHV-06 | Configurable Tool Binding | Optional | 数据来源指南内置 MCP 工具优先级与运行时兜底 |
| BHV-07 | Cumulative Project Library | 未采用（Recommended） | 本工作区约定运行期写入仅限单元根内，跨单元资料库需在单元根外写入，故不采用；同国重跑通过单元根内既有材料复用实现 |
| QUA-01 | Embedded Quality Standards | Recommended | 完成标准以可勾选清单嵌入各 Blueprint |
| QUA-03 | Verifiable Data Lineage | Required | SRC 编号链 + 两次独立上下文核验 |

| BHV-08 | Wiki Integration | 未采用（Optional） | 交付格式仅为 Markdown 研究报告 |

## 如何运行

本系统需在具备 AI 理解的智能运行时（如 DSH、Claude Code、Cursor 等）中执行，运行时需提供文件读写、子代理（subagent）与网页搜索/抓取能力（工具优先级见 `references/methodology/data-sources.md`）。

1. 进入项目目录：`cd ai-strategies-of-gs-countries`
2. **运行一个国家单元**（一次调用驱动该国的全流水线）：

   > 请读取 `agents/00.orchestrator.md` 并严格按照该 Blueprint 执行。
   > 参数：COUNTRY_ID=brazil、COUNTRY_NAME=巴西

   国家单元键见 `references/methodology/countries.md`（与 `pomasa.json` 的 `work.units` 一致）。

3. **多国并行**：为每个国家分别启动一个编排者实例（独立消息、独立上下文），每批 ≤7 个（BHV-03）。
4. 交付物：`workspace/{COUNTRY_ID}/07.report/final_report.md`（也可在 `workspace/{COUNTRY_ID}/` 逐层查看中间产物）。

运行约束说明：

- 编排者在 `workspace/{COUNTRY_ID}/run.json` 记录各阶段状态（OBV-03），中断后可从文件恢复判断进度。
- 深度收集/分析/分节阶段会以 ≤7 的批次并行执行；数据核验必须 100% 覆盖（禁止抽样）。
- 按工作区约定，运行期所有写入（含运行笔记）都在单元根 `workspace/{COUNTRY_ID}/` 内；重新运行同一国家时，扫描与收集代理会先复用单元根内既有材料（同国重跑，避免重复抓取）。
- 若某阶段代理上报"无法完成"，编排者记录到 `workspace/{COUNTRY_ID}/notes.md` 并上报；完成标准不可降低（BHV-02）。

## 如何调整

- **改研究范围/立场/四方向定义**：编辑 `references/methodology/research-overview.md`
- **改国别清单或加国家**：编辑 `references/methodology/countries.md` 并同步 `pomasa.json` 的 `work.units`
- **改数据来源与可信度评级**：编辑 `references/methodology/data-sources.md`
- **改分析框架/引用规范**：编辑 `references/methodology/analysis-methods.md`
- **改报告结构/格式规格**：编辑 `references/methodology/output-template.md`（改分节方案须同步 `pomasa.json` 契约、`agents/06.section_writer.md` 与 `agents/07.reporter.md`）
- **改领域背景知识**：编辑 `references/domain/` 下文件
- **改代理行为/完成标准**：编辑对应 `agents/NN.xxx.md`
- **改运行划分（如增维度）**：编辑 `pomasa.json` 的 `work` 段
- **重要**：改动 Blueprint 中的产物契约（OBV-01）或阶段划分后，应同步更新 `pomasa.json` 的 `stages[].contracts[]`（OBV-01 要求二者一致）

## 术语约定

- 方向代码：`dev`（发展：AI 基建/应用/治理/能力建设）、`geo`（地缘政治与中美关系）、`policy`（立法/产业政策/国际合作）、`actors`（关键部门/政治家/思想领袖）
- SRC：原始材料编号（如 `SRC-dev-01`），全链唯一、可核验；ANA：分析材料编号（如 `ANA-geo-01`）
- 报告引注：脚注形式 `[^SRC-xxx]`，定义统一置于文末脚注定义区（用户明确规格）
- Verified sources：`workspace/{COUNTRY_ID}/03.verification/verified_sources.md`（后续阶段唯一合法引用来源）
