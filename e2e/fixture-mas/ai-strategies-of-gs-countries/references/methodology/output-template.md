# 报告模板（Output Template）

> 本文件规定最终报告的结构、分节方案与 Pandoc-Ready Markdown 格式规范（STR-06 + STR-05 + STR-08，含用户指定的隐含格式规格）。分节撰写员与报告装配师必须严格遵循。

## 报告结构与分节方案

每国一份报告，由 7 个分节构成（分节在 `06.sections/` 独立成文，最终由报告装配师组装为 `07.report/final_report.md`）：

| 分节号 | 分节名（文件名 slug） | 分节标题（中文） | 内容要点 | 主要素材来源 |
|--------|------------------------|------------------|----------|--------------|
| 00 | cover | （封面节：唯一允许使用 `#` 的节） | 报告标题（`#`，唯一一级标题）、元信息（国家、报告日期、数据窗口）、300-500 字中文摘要（研究范围、方法与主要发现概述） | `01.country_scan/country_brief.md`、各分析文件 |
| 01 | overview | 国别 AI 战略总览 | 该国 AI 战略的形成脉络、核心文件/机构、总体定位；先给读者一幅全图 | `country_brief.md` + 四个分析文件 |
| 02 | dev | AI 基建、应用、治理与能力建设：问题与前景 | 方向 `dev` 的完整分析 | `04.analysis/dev_analysis.md` |
| 03 | geo | 地缘政治背景下与中美两国的关系 | 方向 `geo` 的完整分析 | `04.analysis/geo_analysis.md` |
| 04 | policy | 立法、产业政策与国际合作策略 | 方向 `policy` 的完整分析 | `04.analysis/policy_analysis.md` |
| 05 | actors | 关键政府部门、政治家与思想领袖 | 方向 `actors` 的完整分析 | `04.analysis/actors_analysis.md` |
| 06 | conclusion | 结论与展望 | 综合四个方向给出该国 AI 战略的总体判断、前景展望、与中美关系的走向判断（标注推断与不确定性）、信息缺口清单 | 全部分析文件 + `01.country_scan/research_checklist.md` |

**引文脚注**：正文中的引用统一写作 pandoc 脚注 `[^SRC-xxx]`；**脚注定义区（`[^SRC-xxx]: …`）不写在任何分节内**，由报告装配师在最终报告中统一置于文末（见下）。

## 分节撰写格式规范（STR-08 Pandoc-Ready Markdown）

分节撰写员产出的每个分节文件必须满足：

### 标题

- [ ] 全文档**只有一个**一级标题 `#`（在 00.cover 节的报告标题处）；其他所有分节**必须**以 `##` 开始，禁止使用 `#`
- [ ] 层级连续不跳级（`##` → `###` → `####`，不得从 `##` 直接跳到 `####`）
- [ ] 标题前后各留一个空行

### 段落与留白

- [ ] 段落之间一个空行
- [ ] 分节文件首行与末行各为一个空行
- [ ] 行尾无多余空格

### 列表

- [ ] 列表前后各留一个空行
- [ ] 列表统一用 `-`；嵌套列表用 2 空格缩进
- [ ] 有序列表使用 `1.` 格式

### 代码块 / 引用 / 表格

- [ ] 代码块用 ``` 括起（标注语言），前后空行
- [ ] 引用块每行以 `>` 开头，前后空行
- [ ] 表格前后空行，表头与表体之间有分隔行，无空单元格

### 引文（脚注，用户明确规格）

- [ ] 正文引用处以 `[^n]` 标注，键名使用来源编号：`[^SRC-dev-03]`（形如 `[^src01]` 的命名，本系统用 SRC 编号保证全链唯一）
- [ ] 脚注定义 `[^SRC-xxx]: …` **不写进分节文件**（由报告装配师统一放到文档末尾的脚注定义区）
- [ ] 不得把引注写成内联链接 `[文字](url)` 或堆在文末的大段列表里
- [ ] 只有保留清单（`03.verification/verified_sources.md`）中的 SRC 可以被引用

### 中文排版（用户明确规格）

- [ ] 使用全角标点：引号 `“”`、顿号 `、`、逗号 `，`、句号 `。`、冒号 `：`、括号 `（）`、书名号 `《》`
- [ ] **禁止**在中文语境使用 ASCII 直引号 `"` `'`（AI 常见错误，必须自查修正）

## 最终报告结构（报告装配师执行）

```
# {国家中文名}AI战略研究报告            ← 唯一一级标题（来自 00.cover）

（元信息 + 摘要，来自 00.cover）

## 国别AI战略总览                        ← 01.overview
……
## AI基建、应用、治理与能力建设：问题与前景   ← 02.dev
……
## 地缘政治背景下与中美两国的关系            ← 03.geo
……
## 立法、产业政策与国际合作策略              ← 04.policy
……
## 关键政府部门、政治家与思想领袖            ← 05.actors
……
## 结论与展望                             ← 06.conclusion
……

## 脚注定义                               ← 装配师追加，文档末尾

[^SRC-cnt-01]: 标题（来源类型）。URL

[^SRC-dev-03]: 标题（来源类型）。URL

……
```

脚注定义区规则：

- 从组装后的正文中提取全部 `[^SRC-xxx]` 键，对照 `03.verification/verified_sources.md` 保留清单生成定义（格式：`[^SRC-xxx]: 文档标题（来源类型）。URL`）
- 发现正文引用了保留清单之外的 SRC（孤儿引用）→ 必须在交付说明中列入“待修复问题”并尽可能修复（删除该引用或换算为合规来源）
- 定义区前加空行、每条定义独立成行，保证 pandoc 可解析

## 写作风格

- 客观、学术、中立的书面中文；避免主观评价词（“令人震惊”“伟大”等）
- 术语统一（国家名、机构名、SRC/ANA 编号）；机构名首次出现给出中文名与英文名
- 多用具体事实与数据，少用空泛概括；篇幅以内容定，不凑字数
- 对推断内容明确标注（推断）并说明依据与不确定性

## 交付前质量检查清单（报告装配师与编排者验收共用）

- [ ] 全文仅一个 `#` 标题；章节均为 `##` 及以下，层级连续
- [ ] 所有块级元素（标题/列表/代码块/引用/表格）前后有空行；列表统一 `-`，嵌套 2 空格缩进
- [ ] 全部引注为 `[^SRC-xxx]` 脚注形式；脚注定义区在文末且覆盖正文全部键；无孤儿引用
- [ ] 中文全角标点；无 ASCII 直引号
- [ ] 四个方向章节齐全、顺序正确、内容完整
- [ ] 结论章包含推断标注、不确定性说明与信息缺口
- [ ] 全文无未追溯来源的事实（QUA-03）
