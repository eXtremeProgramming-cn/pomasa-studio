# HarmonyOS_Sans_SC_Regular.ttf

CJK-capable font bundled so the pure-JS PDF exporter (pdfkit) renders Chinese
text without depending on pandoc or any system font.

- Font: HarmonyOS Sans SC Regular
- Source: HarmonyOS Design Resources via
  https://github.com/huawei-fonts/HarmonyOS-Sans (raw TTF from the TCOTC
  siyuan mirror: HarmonyOS_Sans_SC_Regular.ttf, unmodified)
