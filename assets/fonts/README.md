# DroidSansFallbackFull.ttf

Compact CJK fallback font bundled so the pure-JS PDF exporter can render
Chinese text without depending on pandoc or any system font.

- Source: Android Open Source Project `frameworks/base/data/fonts/DroidSansFallbackFull.ttf`
